# Hosted Scheduler And Multi-Node Services

> Port now ships a single-node hosted control-plane demo, but it still lacks host-group-aware scheduling and multi-node service placement. To move closer to Slicer-class hosted operation, Port needs explicit host groups, placement policy, and service execution that can target prepared nodes without inventing a second CLI or service model.
