## Observations

The imported inventory slice fit cleanly onto the existing hosted registration and placement persistence pattern once the state file and validation helpers were given their own path-aware error surface. The main surprise was that the wider crate verification exposed pre-existing parallel test flakiness caused by environment-variable mutation in hosted-control tests, so the story also needed a repository test-harness stabilization step to keep default `cargo test` deterministic.
