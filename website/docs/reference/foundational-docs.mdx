## Why The Site And Root Docs Both Exist

The public docs site helps a new operator answer:

- where should I start?
- what is the current local path?
- what is the strongest current cloud path?
- what should I do on Linux, macOS, or Windows?

The root docs answer the more exact questions:

- what is the hard contract?
- what are the exact runtime and artifact assumptions?
- what is shipped versus planned?

Use both. The site should guide you to the right contract, not replace it.
